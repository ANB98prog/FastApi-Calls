# API сохранения звонков и получение статистики по ним

## Архитектура
Приложение сосотоит из следующих компонентов:
* Kafka broker
* Kafka Connect
* Postgres
* FastAPI приложение

## Описание
API принимает список номеров, кладет их в Kafka, после чего Kafka записывает данные в Postgres 

## Методы API
Для пользователя доступны следующие эндпоинты:
* `POST /calls` - принимает номера и сохраняет их в систему
принимает объект вида:
```
 {"anum": 79999999999, "bnum": 79999999999, "timestamp": 1752116172}
```

* `POST /stats` - возвращает статистику по номерам
принимает опциональный параметр:
```
{"anum": 79999999999}
```

Возвращает объект вида:
```
[
    {"anum":79999999999, cnt: 27},
    {"anum":79999999993, cnt: 20},
    {"anum":79999999994, cnt: 14}
]

```

* `POST /health` - возвращает статус состояния системы
Ответ 200 Ок если все ок, иначе 503
